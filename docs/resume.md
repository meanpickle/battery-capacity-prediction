# 简历项目表述

**2025.12｜锂离子电池容量衰退预测（AI 数据驱动）｜主要负责人**

项目描述：针对商用 18650 电池老化过程中的个体差异，开展数据驱动的容量衰退预测研究，统筹模型对比、预处理实验与成果分析。

1. 对比 Transformer、LSTM 与 XGBoost 在循环容量预测中的收敛表现、趋势拟合及局部波动响应，分析不同建模方法的预测特点。
2. 引入 db4 小波分解与重构，对比预处理前后的预测曲线，分析去噪、过度平滑及系统性偏差之间的权衡。

项目成果：留存实验汇报显示 Transformer 与 LSTM 的最终 MSE 均低于 0.005；完成三类模型与小波预处理的对比分析，识别预处理可能造成的预测偏移问题。
